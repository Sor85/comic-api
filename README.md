# Comic API

Python / FastAPI 多图源漫画 WebUI。内置禁漫、哔咔、拷贝漫画；前端按插件能力生成浏览入口与登录表单。

## Fork 说明

本项目 fork 自 [lumia1998/comic-api](https://github.com/lumia1998/comic-api)，基于原项目提交 `7410fa6`（2026-09-25）继续开发。原项目已提供多图源聚合搜索、在线阅读、本地书库、PDF 下载及禁漫账号登录；以下为本 fork 新增的功能与修复的问题，详细说明见后文对应章节。

### 新增功能

- **JM 收藏**：浏览云端收藏夹（分页、排序、本页筛选、多选），漫画详情中可加入 JM 收藏；收藏状态登记在本地表，按账号隔离。
- **哔咔收藏**：浏览账号全部云端收藏，漫画详情中可加入哔咔收藏，同样使用本地状态表。
- **收藏图片同步到本地**：JM 与哔咔收藏可按目录规则增量下载到服务器目录，支持定时同步、单本／所选同步、限速、图片格式与质量、失败重试、SHA-256 文件检查点；「检查本地漫画」可登记已有目录，避免重复下载。JM 额外支持按收藏夹限定范围。下载根目录分别由 `JM_DOWNLOAD_ROOTS`、`BIKA_DOWNLOAD_ROOTS` 限定。
- **云收藏自动同步到书库**：JM 与哔咔收藏可定时增补到「我的书库」的独立分类，不下载图片，默认关闭。
- **搜索增强**：禁漫、哔咔、拷贝三源标签搜索，哔咔分类筛选，作者搜索，以及可选的跨图源搜索结果去重。
- **章节封面预览**：详情页章节列表可显示章节首图，默认关闭，开关状态保存在当前浏览器。
- **阅读记录存服务器**：观看记录与阅读进度改存服务器 SQLite，多设备共享；支持从浏览器旧数据导入。
- **图源开关**：每个图源可独立启用或关闭，关闭后退出搜索、发现与收藏入口，并停止相关任务。
- **站点鉴权**：可选的 HTTP Basic 用户名密码鉴权，默认关闭，可在设置中在线修改。
- **统一设置与界面重构**：设置窗口整合站点鉴权与图源管理；收藏、设置、详情界面重构，采用层叠模态窗口和自绘下拉菜单。

### 修复的问题

- 修复 Fake-IP 代理环境下封面加载失败：图片请求固定已校验的公网连接目标，同时保留代理、TLS 与内网防护。
- 修复哔咔旧图片域名返回 301 时图片加载失败：图片下载支持最多 5 次逐跳校验的重定向。
- 完善 JM 本地检查读取漫画详情失败时的提示：显示失败漫画、阶段与原因，并说明已有文件和登记不受影响。
- 修复书库切换时卡片闪烁、JM 收藏封面重复加载：卡片按 ID 复用，CDN 域名轮换不再触发重新渲染，图片代理返回浏览器缓存头。
- 修复再次进入哔咔收藏时重新显示骨架屏：同一页直接复用已有卡片和封面。
- 修复「继续阅读」点击卡片任意位置都直接进入阅读页的问题，现在仅播放按钮直达阅读页；修复手机上阅读页返回按钮常驻高亮。
- 修复搜索后切换到其他页面再返回发现页时，结果页返回按钮退回上一个页面而非首页的问题。

右上角与移动底栏的「设置」打开统一设置模态窗口，包含「站点鉴权」与「图源管理」。打开和关闭窗口不切换底层页面，不改变搜索条件、地址或滚动位置；关闭按钮、Esc 和遮罩均可关闭，图源子窗口关闭后返回上一层。旧链接 `/?tab=settings` 仍可直接打开首页上的设置窗口。图源列表每行进入独立的图源设置。有登录能力的图源提供「登录凭证」子页面，再填写账号与密码；拷贝漫画提供服务器地址设置，保存到 SQL，优先于环境变量，新请求立即生效。正在执行的请求继续使用原地址；留空可恢复部署默认地址。服务器地址仅接受不含嵌入凭据的 HTTPS URL，只应填写可信服务器。

### 图源开关

「图源管理」每行提供启用开关，内置和自定义图源默认启用。状态保存在服务器 SQLite，对所有浏览器生效，重启后保留；关闭的图源仍显示在管理列表，可重新启用、调整服务器设置或解除账号绑定，登录需先启用图源。

关闭后，该图源退出聚合搜索、发现列表和云收藏入口；直接访问其搜索、详情、章节、图片代理、云收藏及新建／重试下载 API 返回 `409/source_disabled`。等待执行的调用会重新检查开关；已经开始的图源调用允许结束，不强行终止线程。正在运行及排队的 PDF 任务按原有取消流程停止，已完成文件、任务记录、书库、账号凭据和阅读记录均保留。重新启用不会自动重试已取消的 PDF 任务。

关闭 JM 同时停止当前收藏同步／本地检查并暂停定时同步，不删除同步设置、已完成图片或检查点。重新启用后按保留的定时设置恢复，计划已到期时可能立即同步。其他浏览器重新打开图源管理或刷新页面后更新可见状态；服务端请求限制立即生效。

## 部署

```bash
cp .env.example .env
docker compose up -d --build
```

访问 http://localhost:34587 。哔咔和禁漫账号可在「设置 → 图源管理 → 设置 → 登录凭证」绑定；哔咔也可在首次启动前填入 `.env`。拷贝使用游客接口。禁漫收藏夹与自动同步需要账号，登录兼容 JWT 和 AVS Cookie 会话，凭据与会话均加密保存在 SQL。

本地运行：

```bash
pip install -r requirements.txt
python main.py
```

本地端口 8699。只运行一个服务进程 / 一个 Uvicorn worker：下载队列与图源限流器在进程内管理，不支持多个实例共享数据库。站点用户名密码鉴权**默认关闭**；图源账号、书库与下载仍由整个服务实例共享，没有用户隔离或权限分级。未启用鉴权时不要直接暴露到公网。

### 站点鉴权

「设置 → 站点鉴权」提供用户名、新密码、确认新密码，以及鉴权开关：

- 可以先保存凭据，再开启鉴权；也可以填写完整凭据后直接开启。开关与「保存凭据」均提交当前表单内容，开关只在服务器保存成功后更新。
- 修改用户名时可以不修改密码；新密码留空保留现有密码。密码不回显，也不写入浏览器 localStorage/sessionStorage；成功保存、关闭设置窗口或离开页面后清空密码输入。
- 关闭鉴权前显示确认说明，关闭后所有能连接本站的人都可操作实例；已保存的用户名和密码保留，之后可以重新开启。
- 保存到服务器 SQLite 后**立即生效，无需重启**，重启后保留，并优先于环境变量。开启鉴权或在开启状态修改用户名／密码后，当前页面重新加载并通过浏览器内置登录框重新认证；旧凭据立即失效。已经开始的业务请求允许结束。
- 多个页面同时修改时，旧版本保存返回 `409/auth_settings_changed`，不会覆盖新设置；重新读取后才能再次保存。读取或保存失败不假报成功，也不把未知状态显示成关闭。

尚未通过 WebUI/API 保存配置时，以 `.env` 或服务进程的环境变量作为部署默认值：

```dotenv
AUTH_ENABLED=true
AUTH_USERNAME=reader
AUTH_PASSWORD='替换为独立的长随机密码'
```

- `AUTH_ENABLED` 默认 `false`；只有显式开启才要求认证，单独填写用户名或密码不会开启。也支持 `1/0`、`yes/no`、`on/off`，不区分大小写。使用环境变量作为配置时，非法开关或不完整的开启配置会阻止启动，不静默放行；已保存的服务器配置优先，旧环境变量不覆盖它。
- 开启时，用户名与密码必须非空且不能全为空白；用户名不能包含冒号，二者均不能包含控制字符。用户名最多 128 字符、密码最多 1024 字符；支持 UTF-8，密码可包含冒号，首尾空格按原值匹配。没有默认用户名或密码。
- 浏览器访问时使用内置的 HTTP Basic 登录框，不新增站内登录页。页面、静态资源、API 文档、全部业务 API、图片代理、PDF 文件及旧下载入口均受保护；仅 `GET /health` 健康检查公开，固定返回 `{"status":"ok"}`，不含账号或业务数据。
- 未认证或凭据错误返回 `401/auth_required` 与 `WWW-Authenticate: Basic`；图源自身的 `401/login_required` 不触发站点认证挑战。启用鉴权后的受保护响应禁止 HTTP 缓存，避免凭据失效后继续复用受保护内容；服务端图片磁盘缓存保持不变。
- 浏览器跨站写入（包括会创建任务的旧 GET 下载接口）返回 `403/cross_site_request`，避免其他站点利用浏览器自动附带的凭据执行操作。鉴权关闭时也拦截跨站配置写入。同源 WebUI 和不携带浏览器来源头的 API 客户端不受影响；反向代理需保留原始 `Host`。
- 这是一组部署级访问凭据，与图源上游账号无关。SQLite 的 `app_settings/site_auth` 保存开关、用户名、随机盐与 scrypt 密码校验值，不保存站点明文密码；API 仅返回用户名及密码是否已配置，不返回密码、盐或校验值。`.env` 中仍是明文，应限制文件访问权限，不提交到版本库。所有通过认证的人都能操作实例中的图源账号、书库及下载。
- 只有修改仍在使用的部署环境变量时才需完整重启本地服务；Docker 使用 `docker compose up -d --force-recreate` 载入新环境变量，单独 `docker compose restart` 不会更新容器环境。WebUI 保存优先级更高，后续仅修改 `.env` 不会覆盖已保存的配置。凭据由浏览器管理，没有站内退出按钮；切换账号可使用新的隐私浏览会话。

设置 API：`GET /api/settings/auth` 返回 `enabled/username/password_configured/revision/storage`，其中 `storage` 为 `environment` 或 `database`。`PUT` 同一路径提交 `{"enabled":true,"username":"reader","password":"新密码","revision":"最近一次读取的 revision"}`；`password` 省略、`null` 或空字符串表示保留原密码。成功响应包含 `success/settings/reauthenticate`。接口禁止缓存，开启鉴权时读取和保存都需要当前凭据；关闭时不限制可信网络内的访问者管理设置。

忘记站点密码时，由服务器管理员停止服务并备份整个数据目录，配置新的 `AUTH_ENABLED=true`、`AUTH_USERNAME`、`AUTH_PASSWORD`，再通过 SQLite 仅删除 `app_settings` 表中 `name='site_auth'` 的记录后完整启动。此时恢复环境变量配置，不删除数据库、密钥或图源账号；下一次 WebUI 保存后再次由服务器配置接管。已保存的鉴权配置损坏时服务拒绝启动，不降级为开放访问。

API 客户端使用 HTTP Basic，例如以下命令交互式输入密码，不把密码写进命令历史或 URL：

```bash
curl --user reader 'https://comic.example.com/api/library'
```

HTTP Basic 只编码凭据，不加密传输；公网部署必须配合可信反向代理的 **HTTPS**，局域网 HTTP 也会明文传输凭据。建议在反向代理配置登录尝试限流；站点鉴权不提供多用户、角色管理或暴力尝试锁定。

## 数据与功能

- **混合搜索**：各图源结果统一展示并标注来源，按标题完全匹配、包含关键词、字符相似度排序；忽略大小写、全半角与标点差异。排序与去重范围是本次返回的结果（聚合搜索为各源的当前页），不是全站全部漫画，不跨页隐藏记录，也不包含语义理解或简繁转换。
- **作者搜索**：漫画卡片与详情中的作者名称可点击，多作者分别展示入口；使用作者名在全部已启用图源发起关键词搜索，重置页码并清除标签、分类和排序条件。实际匹配范围由各图源的关键词检索决定，不冒充原生作者索引或精确作者筛选。未知作者不提供搜索入口，阅读历史卡片仍保留续读进度。
- **搜索去重**：搜索框下的「结果去重」开关默认关闭，关闭时保留全部原始结果。开启后，关键词、标签、单源和聚合搜索均在当前页合并高置信度重复作品；开关状态随搜索链接与最近搜索保留，切换开关回到第 1 页。合并时保留排名靠前的卡片，并以「作品版本」按钮保留每个图源及同源不同 ID 的原始入口，不修改书库、收藏或阅读进度。同源相同 ID 只显示一次；不同 ID 需规范化标题一致且作者集合相同。只清理可识别的作者、语言和汉化方括号／括号信息，不删除任意副标题、卷号、篇章或版本标记，也不使用模糊标题相似度合并。双方有页数时，允许的差值为较少页数的 3% 向下取整、最少 1 页、最多 4 页；超过即分开。作者缺失时，仅较长标题（规范化后至少 6 字符）及已知页数完全一致才合并；明确作者冲突、通用标题或元数据不足时保留独立结果。合并组内任意两项都须匹配，避免缺失信息串联不同作品。
  页数只取上游返回的作品图片总数：禁漫 `total_photo`、哔咔 `pagesCount`（存在且有效时），拷贝未知；不把章节数或 API 分页数当页数，不为去重逐本请求详情。开启去重时，结果区与「全部」显示合并后的本页作品数，各图源徽标仍表示原始条目数，结果区另列合并数量；关闭时全部数量均按原始结果计算。

- **标签与分类搜索**：详情页保留并展示全部标签，超过 12 项可展开；点击标签在该图源搜索，也可在搜索框下切换「关键词／标签」并输入名称。禁漫使用标签域 `main_tag=3`，哔咔使用 `comics?t=`，拷贝使用 `theme` 题材标识；标签搜索保留图源顺序，不按标题相似度重排。拷贝中文题材先匹配已知题材或完整题材目录，目录缓存 10 分钟，未知题材或目录失败明确报错，不退化成普通关键词搜索。各源标签含义、简繁和匹配规则不保证相同。
- **哔咔搜索分类**：单独查看哔咔搜索结果时显示动态获取的分类，可与关键词或标签搜索叠加；「全部分类」清除筛选，换源时清除原分类及图源专用标签标识。分类目录在当前页面缓存 5 分钟，失败可重试且不阻止普通搜索。搜索 URL 与最近搜索保留搜索方式、图源和筛选条件；旧关键词历史仍可使用。图源分类与个人书库分类互相独立。
- **图片代理**：封面与章节图片统一经 `/api/image/proxy` 中转，浏览器不直接连图源 CDN；校验公网地址并固定实际连接目标（SSRF 防护），最多处理 5 次 HTTP 重定向，每次跳转重新校验并固定目标，底层不自动跟随重定向。成功响应按源+章节+URL 缓存到磁盘（最多保留约 2000 张）。内置图源的 PDF 取图和 JM 收藏同步使用同一网络检查。
- **图源账号**：SQLite 按图源隔离，账号与 Token 使用 AES-GCM 加密。首次启动自动导入原 `.bika_token` / `.bika_credentials.json`，之后以 SQL 为准；退出登录不会重新导入。旧文件不会自动删除，确认迁移成功后可自行清理其中的明文凭据。
- **书库**：收藏、分类、移除、缓存详情与手动检查章节更新；页面支持按分类与标题/作者关键词筛选。同一本漫画的不同图源记录互不覆盖。尚未实现后台定时追更。
- **下载任务**：排队、图片进度、打包状态、取消、失败重试、取回 PDF、删除任务及文件；详情页可一键把全部章节加入队列（已有同章节任务自动去重）。单任务执行，最多 100 个排队任务。重启后未结束的任务标记为中断，需手动重试；重试从头开始，不是断点续传。取消会等待已开始的网络请求或打包操作退出并清理文件。
- **章节封面**：详情页章节栏的开关默认关闭，选择保存在当前浏览器，对禁漫、哔咔、拷贝及其他支持阅读的图源统一生效。开启后以章节首图作预览，仅为可见章节串行获取图片列表，首图地址在当前页面内缓存 10 分钟、失败缓存 30 秒；首图不可用时回退到漫画封面或占位图。关闭开关、离开详情或进入阅读器后停止排队，已经开始的请求可完成并写入缓存。此功能不代表图源原生章节封面，也不会缩小原图文件；拷贝仍遵守章节请求间隔，预览可能逐张出现。
- **阅读进度**：保存在服务器 SQLite（`reading_comics` 记录每本漫画最后阅读位置，`reading_chapters` 记录每章页码），按图源、漫画和章节隔离，对所有浏览器与设备共享，重启后保留；支持续读、滚动/翻页模式。阅读中的翻页合并约 0.8 秒后写入，关闭阅读器、切到后台或离开页面时立即提交，写入失败时提示并每 5 秒重试；页面重新回到前台时重新读取，获取其他设备的最新进度。「清除记录」只清空「继续阅读」列表，各章节页码保留，再次阅读后重新出现在列表中。旧版本保存在浏览器 localStorage 的阅读记录在首次打开页面时自动导入服务器，导入成功后从浏览器删除，服务器上较新的记录不会被覆盖。主题、阅读模式、最近搜索等偏好仍保存在当前浏览器。
- **明确错误**：接口区分登录失效、限流、网络超时、上游错误与参数错误。聚合搜索保留可用图源结果，并单独报告失败源，不把失败伪装成空结果。
- **并发边界**：每源最多 2 个业务调用；每客户端最多 4 个网络请求；阅读图片最多 8 个并发处理；PDF 默认最多 4 个图片下载。同步请求在线程执行，取消等待不会提前释放仍在工作的线程配额。拷贝章节请求间隔至少 6 秒，并缓存成功结果 10 分钟。

默认数据目录为 `./data`，可用 `DATA_DIR` 修改。Docker 已挂载 `./data:/app/data`：

| 路径 | 内容 |
| --- | --- |
| `comic.sqlite` | 站点鉴权配置与密码校验值、图源凭据密文、书库、下载记录、按图源和账号隔离的 JM／哔咔收藏状态表 |
| `credentials.key` | 凭据加密密钥，必须保密并与数据库一起备份 |
| `downloads/` | 已生成的 PDF |
| `jm-favorites/` | 默认 JM 收藏图片同步目录（可在允许的根目录内修改） |
| `plugins/` | 自定义可信 Python 图源 |

备份建议先停止服务再复制整个数据目录，避免遗漏 SQLite WAL。密钥丢失后无法解密旧账号。加密不防御可同时读取数据库和密钥的主机管理员。PDF 密码显示在任务卡上，沿用确定性六位密码，主要用于阅读流程而非强机密保护。

### 代理与 Fake-IP DNS

图片下载优先读取服务进程的 `HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY` 环境变量（兼容小写）；没有代理环境设置时，读取 Python 支持的操作系统代理配置（包括 macOS 系统代理）。遵守 `NO_PROXY` 的域名、端口及 IP/CIDR 排除规则，以及系统代理的例外规则。代理由部署者配置，必须可信，不能来自用户请求参数。普通图源 API 请求保持原有客户端行为。

Surge 等代理的 DNS 可能把公开 CDN 域名映射到 `198.18.0.0/15` 虚拟地址。项目不会直接放行这个网段：只有存在未被 `NO_PROXY` 排除的代理时，才经该代理向 Google Public DNS 的 HTTPS 接口查询真实公网地址。DNS 查询只包含域名和记录类型，不包含图片路径、查询参数或图源账号凭据；解析器自身连接固定到 `8.8.8.8` / `8.8.4.4`，保留 TLS 证书校验，避免再次依赖 Fake-IP DNS。

取得公网结果后，通过 libcurl `CONNECT_TO` 固定实际目标 IP，保留原域名的 Host 和 TLS SNI；HTTP 代理也使用 CONNECT 隧道，避免代理重新解析目标而绕过检查。并发查询按域名与代理合并，结果按 DNS TTL 缓存，最长 300 秒、最多 512 项。直连也固定已校验的公网 IP，避免检查与连接之间的 DNS 重绑定。

以下情况仍会失败，不降级为无校验访问：直接输入 Fake-IP/私网/回环/链路本地地址；DNS 返回真实私网地址；Fake-IP 没有对应代理或被 `NO_PROXY` 排除；HTTPS DNS 解析失败或返回非公网结果。图片代理和 PDF 取图支持 301、302、303、307、308 跳转及相对目标地址，但每一跳都必须通过相同的地址、DNS 与代理检查；缺少目标、循环或超过 5 次的跳转会明确报错。JM 收藏同步的流式取图仍要求最终 CDN URL，不跟随重定向。

本机服务通常可直接沿用现有代理环境，无需关闭 Surge 或放宽 SSRF 防护。Docker 内使用宿主机代理时，需要显式传入容器可访问的代理地址；容器内的 `127.0.0.1` 不是宿主机。环境变量变化后需要重启服务。

## 云收藏自动同步到书库

「设置 → 图源管理 → JM／哔咔设置 → 收藏同步到书库」提供独立开关，两源均**默认关闭**。开启前需要启用图源并绑定账号；设置保存在服务器 SQLite，对全部浏览器生效，重启后保留。该功能独立于 JM 图片下载同步，不会开启图片下载。

- 开启后立即在「我的书库」创建「JM 收藏」或「哔咔收藏」分类，即使云收藏为空也保留该分类；后台立即扫描全部收藏分页，之后默认每 60 分钟增补。仅在服务运行时执行，无需保持浏览器打开；服务重启后继续已保存的计划，中断的轮次会重新扫描。
- 只获取收藏列表及新入库漫画的完整详情与章节元数据，不请求章节图片、不创建 PDF 或图片下载任务、不修改远端收藏。JM 使用全部收藏（`folder_id=0`，含所有收藏夹），哔咔使用账号的全部收藏；最多扫描 1000 页。
- 按图源和漫画 ID 幂等入库。已存在的书目只补充自动分类关联，保留原详情及手动分类，不自动追更。同一本漫画可同时出现在手动分类和自动收藏分类中，但「全部分类」只显示一次；「未分类」表示没有任何手动或自动分类。
- 修改手动分类、手动刷新详情不会移除自动分类关联。关闭同步、关闭图源、解除账号绑定或远端取消收藏均不删除本地书目与分类。手动移出书库会移除该书的分类关联；若云端仍收藏且自动同步保持开启，后续轮次会再次导入。
- 关闭图源时停止当前入库、暂停计划并保留开关；重新启用后按原计划恢复。登录或解除绑定会关闭该源的书库同步，避免新账号沿用旧计划，原书库内容保留。已发出的请求允许结束，但关闭／换号后的迟到结果不会继续入库。
- 两源独立执行。重复页、总数变化或不完整扫描报错，本轮不导入；单本详情失败不阻止其余漫画入库，失败项在后续轮次重试。「刷新状态」显示进度及错误并刷新书库，「立即同步」可提前执行下一轮，不能重入正在运行的任务。

API：`GET /api/sources/{source}/library-sync` 读取设置、分类名、当前状态及下次执行时间（Unix 秒）；`PUT` 同一路径保存 `{"enabled":true,"interval_minutes":60}`，间隔范围为 5–10080 分钟，省略字段使用默认值；`POST /api/sources/{source}/library-sync/run` 在开关开启时立即运行，无请求体。仅支持 `jm`、`bika`。`GET /api/library` 保留原有手动分类字段 `library_category`，另返回并集 `library_categories`；`?category=` 按分类并集筛选，空字符串筛选真正未分类的漫画。

## 哔咔收藏

导航「哔咔收藏」（或 `/?tab=bika-favorites`）读取已绑定哔咔账号的全部云端收藏，支持分页、最新／最旧上架／最多喜欢／最多观看排序及本页标题、作者筛选。桌面导航、移动导航和哔咔图源设置均提供入口。收藏默认与「我的书库」独立，可通过独立开关自动同步到书库；哔咔没有命名收藏夹或分组，本项目也不提供取消收藏，阅读与 PDF 下载沿用原有功能。

页头「本地同步」打开与 JM 共用的同步窗口，可把收藏图片增量保存到服务器目录，详见下方 [哔咔收藏图片同步](#哔咔收藏图片同步)。

漫画详情的「加入哔咔收藏」沿用 JM 的交互与本地状态表：每次打开详情通过 `GET /api/bika/favorites/{comic_id}` 仅读取当前账号在 SQLite 中的记录，返回 `comic_id/favorited`，其中 `true/false/null` 分别表示已收藏、已确认未收藏和未知；不额外访问哔咔或加载章节。未知仍显示加入按钮并说明添加前实时检查远端；读取失败显示「收藏状态未确认」，点击只重读状态。状态接口和收藏列表响应均禁止缓存。

收藏分页拉取时登记本页记录；同一排序下，从首页开始连续读取、页大小与总数一致且去重数量匹配的完整列表，才原子替换该账号的索引，并将未出现的漫画判定为未收藏。部分分页、乱序、重复、失败或发生数量变化时不删除已有记录、不把未出现项当作未收藏。本地表按账号指纹隔离，与 JM 收藏表及书库独立，重启和重新绑定同一账号后保留；其他哔咔客户端的改动需刷新收藏分页后更新。

`POST /api/bika/favorites/{comic_id}` 无请求体，漫画编号为 24 位十六进制字符串；成功返回 `success/comic_id/favorited/already_favorited`。添加前实时请求上游 `GET comics/{id}` 并严格检查 `isFavourite` 布尔值，不用本地缺失记录判断是否写入，也不扫描全部收藏或加载章节。已收藏直接成功；未收藏仅发送一次 `POST comics/{id}/favourite`，验证 `data.action=favourite` 后登记。预检查与写入串行且与账号登录、退出互斥；禁用写入请求的重定向及会话失效后的自动重发。

网络失败或响应不完整时，该漫画状态保留为未知，不自动重发切换；再次添加仍先查询远端。上游返回 `un_favourite` 时登记为未收藏并报告并发冲突，不自动补偿。上游不提供原子“仅添加”，其他客户端在预检查与写入之间修改收藏仍可能产生冲突。站点鉴权默认关闭，未开启时任何可访问服务的人都可操作绑定账号；公网部署必须启用访问认证并配置 HTTPS。

协议依据：[pica-go 请求实现](https://github.com/niuhuan/pica-go/blob/master/client.go)、[分页及收藏状态字段](https://github.com/niuhuan/pica-go/blob/master/dto.go)、[收藏动作枚举](https://github.com/niuhuan/pica-go/blob/master/enum.go)。

### 哔咔收藏图片同步

哔咔收藏页的「本地同步」、卡片封面左上角的「同步本书」、「选择本页 / 同步所选」与 JM 使用同一套同步窗口、任务卡片、设置与服务器目录选择，行为与下文「同步行为」「检查已有漫画」「下载设置」一致，差异如下：

- 同步范围固定为账号的全部收藏（哔咔没有收藏夹），整轮扫描使用「最旧上架」排序逐页读取，按漫画 ID 去重后获取最新详情与章节。
- 漫画 ID 为 24 位十六进制字符串，章节 ID 为章节序号；带 ID 的目录规则写作 `漫画标题 [5e7f…]/001 - 章节标题 [1]`。不提供 JM 专用的「【作者】原标题 / 第N話 章节标题」规则。
- 下载根目录由 `BIKA_DOWNLOAD_ROOTS` 控制，默认 `DATA_DIR/bika-favorites`，规则与 `JM_DOWNLOAD_ROOTS` 相同（见「服务器目录选择」）。
- 任务记录、文件检查点与本地检查登记存放在独立的 `bika_sync_runs`、`bika_sync_files`、`bika_sync_local_files` 表；JM 与哔咔可同时运行各自的任务，设置与定时计划互不影响。
- 「同步添加到本地书库」使用「哔咔收藏」分类，已有分类不变。更换或解除哔咔账号绑定后定时同步自动关闭；任务运行时拒绝账号变更。
- 图片原样保存（哔咔图片无需反切割），格式转换、质量、限速与重试设置同 JM。

API 与 JM 相同，前缀换成 `/api/bika/sync`；`POST /api/bika/sync/run` 的 `album_ids` 为最多 200 个 24 位十六进制漫画 ID，设置不含 `folder_ids`。

## JM 收藏与图片同步

导航「JM 收藏」（或 `/?tab=jm-favorites`）读取已绑定账号的云端收藏，支持自建收藏夹、分页、按收藏时间或漫画更新时间排序、本页标题/作者筛选及多选。`0` 是全部收藏，包含未放入自建目录的漫画。收藏浏览与本地「我的书库」是独立概念；浏览、同步及本地书库操作不会修改远端收藏。

### 加入 JM 收藏

禁漫漫画详情中的「加入 JM 收藏」写入已绑定账号的云端收藏，与「加入书库」互相独立；不指定收藏夹，也不提供取消收藏。未绑定账号时显示账号绑定入口。每次打开详情都读取当前账号的本地收藏表，读取期间禁用按钮并显示「读取 JM 收藏…」；表中已收藏显示「已收藏」，未收藏或尚未记录显示「加入 JM 收藏」。尚未记录时状态仍为未知，按钮说明会标明添加前实时检查远端，不把未知当作未收藏；读取失败显示「收藏状态未确认」，点击只重试读表。关闭详情、刷新或重新打开页面不会依赖旧按钮状态。处于 JM 收藏页时，添加成功后刷新当前收藏列表。

状态 API：`GET /api/jm/favorites/{comic_id}` 返回 `comic_id/favorited`，**仅查本地 SQLite 表，不访问 JM、不恢复远端登录态、不扫描收藏分页**。`favorited=true/false/null` 分别表示已收藏、已确认未收藏、未知。HTTP 响应禁止浏览器及代理缓存，其他页面每次读表都取得最新已登记状态。

收藏页分页拉取、定时或手动同步、检查本地漫画时，已拉取到的收藏立即更新 `jm_favorites` 表。完整读取「全部收藏」（`folder_id=0`）的连续分页、总数及去重数量校验通过后，原子替换该账号的完整索引；之后未出现的漫画才可确认为未收藏。单页、指定收藏夹、乱序分页或失败扫描只更新已取得的记录，不删除未出现项，也不将它们误判为未收藏。仅下载指定漫画、保存本地书库或读取漫画详情不会伪造远端收藏记录。

加入收藏前仍实时读取远端完整收藏，不使用本地表的缺失记录直接触发切换接口；添加成功立即登记为已收藏。写入结果不确定时仅将该漫画标记为未知，保留其他记录；上游明确返回取消收藏时登记为未收藏并报告冲突。

本地表按账号名指纹隔离，与本地书库独立，无 60 秒过期机制；关闭页面、退出后重新绑定同一账号或重启服务均保留已登记数据，换账号不混用。其他 JM 客户端修改收藏后，需要再次拉取收藏或运行收藏扫描，表才会按新结果更新；详情页不会为确认状态额外拉取远端。旧版本未保存已拉取的收藏状态，升级后在「JM 收藏」刷新页面或运行已有收藏扫描即可建立索引。

API：`POST /api/jm/favorites/{comic_id}`，无请求体，漫画编号为 1–20 位正整数字符串。成功返回 `success/comic_id/favorited/already_favorited`；已有收藏返回成功及 `already_favorited=true`，不会再次调用上游切换接口。

上游 `POST /favorite` 是切换而非幂等添加。每次添加前实时检查全部收藏分页，最多 1000 页；分页失败、重复、总数变化或数量不一致时拒绝写入。检查与写入在当前实例中串行处理，并与账号登录、退出互斥。写入只发送一次，不做网络失败、坏响应或会话失效后的自动重发；结果未确认时返回错误，再次操作会重新检查远端状态，不使用本地书库或当前页缓存推断未收藏。

上游未提供原子“仅添加”操作，其他 JM 客户端在检查与写入之间更改收藏仍可能造成并发冲突；上游返回 `remove` 时明确报错，不自动补偿或重发。收藏较多时预检查可能耗时较长。站点鉴权默认关闭，未开启时任何可访问服务的人都可能操作所绑定账号；开启后本接口也要求站点凭据。

### 同步行为

- 「同步收藏」按设置中的范围扫描全部分页；「同步本书」「同步所选」直接同步指定漫画，不受收藏夹范围限制。
- 定时同步默认关闭。保存并启用后立即执行，之后以每轮结束时间加间隔计算下一轮（5 分钟到 7 天）。只在服务运行时执行，浏览器可以关闭；服务重启后按保存的计划继续。
- 单个同步 worker，漫画、章节和图片依次处理。已有任务运行时拒绝重入及设置/账号变更；需要先停止并等待结束。更换或解除禁漫账号绑定后关闭定时同步，避免用新账号意外继续旧计划。
- 全部收藏逐页扫描，按漫画 ID 去重，再获取最新详情与章节，因而会补充新增章节。发现重复页、总数变化或不完整响应时明确报错，不把失败当作空收藏；远端持续变化时可稍后重试。
- 文件清单持久化到 SQLite，按输出配置、漫画、章节和页码记录 URL 路径、文件位置、大小与 SHA-256。存在且校验一致的图片跳过，缺失或损坏的已记录图片重新下载；失败项在下一轮重试，不重复下载已完成项。
- 停止与重启保留已完成图片；中止当前请求后结束。没有字节级断点续传，未完成的单张图片会重新下载。任务记录保留最近 30 次，页面显示最近 10 次，每轮保留前 100 条失败明细。
- 可同步添加到本地书库，已有分类不变，新漫画使用「JM 收藏」分类。远端取消收藏、删夹或清空后不会删除本地书库和文件。

### 检查已有漫画

「检查本地漫画」按同步设置中的收藏夹范围读取云端收藏，在已配置的服务器下载目录中查找对应漫画。检查只读取收藏、章节和图片地址等元数据，不下载图片，不修改、重命名或删除已有文件。检查与下载共用单任务锁，可通过「停止本次任务」取消；检查不会推迟原有定时同步计划。

- 支持现有三种带 ID 的目录，以及 `下载根目录/漫画名/章节名/图片`；章节也支持 `第1話 章节名`、`第1话 章节名`、`001 - 章节名` 形式。下载根目录应选所有漫画文件夹的上一级，不是某本漫画或某章的目录。例如 `本子/漫画名/第1話 章节名/00001.jpg` 应选择 `本子`。
- 优先用目录中的漫画、章节 ID 匹配；不带 ID 时按完整标题匹配，兼容 Unicode 宽窄字符、大小写、空白及本工具的文件名清理/截断规则。不做模糊标题搜索；同名漫画、重复目录、多个章节指向同一目录均不自动认定为已下载。其他工具自行改名的目录可能无法匹配。
- 核对远端全部章节与每章图片数量，图片需按从 1 开始的连续页码命名（补零位数不限），或与远端图片文件名主体一一对应。缺章、缺页、重复页码、多余页码会报告异常；`cover/folder/thumb/poster` 命名的封面图片、隐藏文件和非图片元数据不计入页数。
- 每张图片验证格式、完整解码（动图检查全部帧），记录大小和 SHA-256；单文件上限 64 MiB。只有整本通过检查才登记，不把空目录或仅有书库记录视为已下载。页面显示已下载本数、图片数、未匹配本数及异常明细，保留前 100 本已下载漫画的路径。
- 外部图片单独登记到 SQLite，不获得本工具下载文件的覆盖权限。后续手动或定时同步重新核对图片 URL 路径、文件大小与 SHA-256，通过则跳过；新增章节仍正常下载。导入的图片不因格式、质量或目录层级设置变化而重新转换，新增图片按当前设置输出。变更下载根目录后需重新检查。
- 原有外部图片损坏或缺失时不会继续跳过，后续同步会尝试按当前规则下载；如目标位置已有未授权覆盖的外部文件，则保留原文件并报告冲突。仅存在于本地、不在指定收藏范围内的漫画不登记、不删除。启用“同步添加到本地书库”时，只将检查通过的漫画加入书库，已有分类不变。

这里的校验是**目录身份匹配、页数完整性与图片可读性检查**。远端没有可用的内容摘要，首次检查不能证明本地图片与远端内容逐字节相同，也不能自动判断是否已经正确反切割；SHA-256 用于识别登记后本地文件的变化。标题缺少 ID、目录改名或图片命名不明确时，检查宁可报告未匹配/异常，不按文件数量猜测归属。

新下载的 `title` 规则依然是 `漫画标题 [ID]/001 - 章节标题 [ID]/图片`。只需保留完整漫画标题、不合成作者与原标题时，在「目录层级」选择 **漫画标题 / 第N話 章节标题**（无 ID 规则，`title_plain`，不等同于 `Aauthoroname`），输出为 `漫画标题/第1話 章节标题/00001.jpg`、`漫画标题/第2話 章节标题/00001.jpg`。编号从 1 开始、不补零，使用繁体“話”和一个空格，不添加漫画/章节 ID 或 `001 -`。章节标题已有同序号的“第N話/第N话”前缀时不重复添加。图片编号与格式设置保持不变。

无 ID 规则保留完整合法标题，不沿用带 ID 规则的 100 字节标题截断；Windows 非法字符和保留名称仍作安全处理。单个目录名超过 255 UTF-8 字节时明确失败，不静默缩短或附加 ID。不同漫画 ID 不允许写入同一个已登记的无 ID 漫画目录，以免同名漫画混合。旧的三种规则和已有设置不变，不自动切换、搬移或重命名已有目录；本地检查也不要求为旧目录补上 ID。选择无 ID 规则时检查优先匹配完整标题，因此标题内的数字或 `[数字]` 不会优先当作附加 ID。

### JMComic-kit 兼容目录

「目录层级」中的 **【作者】原标题 / 第N話 章节标题** 对应 JMComic 的 `Bd_Aauthoroname_Pindextitle` 规则。选项统一使用中文目录结构描述，API 设置值仍为 `Bd_Aauthoroname_Pindextitle`；不是普通标题规则，也不是单独增加一层作者目录。

```text
本子/                                      ← Bd：服务器下载根目录
└── 【ひとにたち】ヒトメボレ/                ← Aauthoroname
    ├── 第1話 [漢化組] [ひとにたち] ヒトメボレ/  ← Pindextitle
    │   └── 00001.jpg
    └── 第2話 章节完整标题/
        └── 00001.jpg
```

命名与 JMComic 2.6.13、commonX 0.6.40 的实际代码一致（不启用繁简转换）：

- `Aauthoroname` 为 `【第一位作者】原标题`，使用中文 `【】`，括号后不额外插入空格。保留第一位作者原始内容，不把多个作者拼接起来；没有作者时使用原库的 `default_author`。
- `oname` 从已去除首尾空白的漫画标题中取**首个不属于括号块的文本片段**。支持嵌套的 `()`、`[]`、`【】`、`（）`；不删除所有括号后再拼接，也不按空格拆词。全标题都是括号块时回退完整标题。“原标题”是原库的字段名，并不强制选择日文名称。
- `Pindextitle` 为 `第{序号}話 {章节完整标题}`。使用 `/chapter` 返回的实际名称、`series` 中当前章节的 `sort` 和 `series_id`，不依赖收藏列表标题、漫画详情中的章节简称或本次循环序号。章节列表中没有当前章节时序号默认为 1；仅当 `series_id=0` 且 `sort=2` 时按原库改为 1。序号不补零，繁体“話”后追加一个半角空格，**不去重章节名称原有的“第N話”**。单章节使用真实章节标题，不把界面上的“开始阅读”作为目录名。
- Windows 禁止字符 `\\/:*?"<>|` 及换行、制表、回车替换为 `_`；先清除末尾句点，再去除整个目录名的首尾空白。保留原库的处理顺序，不套用本项目普通标题规则的截断、括号替换或前缀去重。
- 不追加漫画/章节 ID，不截断长名称；空名称、NUL 或超过 255 UTF-8 字节的目录名明确报错。目录范围、符号链接限制和不同漫画不得混写同一已登记目录的保护继续生效。这里只兼容目录命名，图片文件名、编码格式与质量仍由本项目设置控制。

已有该结构的漫画，先保存这条目录规则及下载根目录，再执行「检查本地漫画」。该规则下，检查先获取同步范围内所有漫画的详情、第一作者与原标题，排除不同收藏生成同一目录的情况，再按同一命名函数匹配漫画目录与真实章节目录。详情获取失败时停止本次检查，不使用不完整作者数据推测归属；同名歧义、缺章、缺页、损坏均不自动登记。完整漫画登记后，后续同步校验并跳过原文件，新增章节也按本规则输出。原目录不搬移、不重命名，已有设置不自动切换。

详情预读取失败时，结果卡片会直接显示失败收藏的标题（缺失时仍显示漫画 ID）、原始错误原因及重试说明；失败记录中的 `errors` 条目保留 `stage=matching`、`album_id` 和错误 `code`，刷新页面或重启服务后仍可识别失败阶段。整轮中止规则不变：该阶段失败时本轮尚未开始本地图片校验，也未新增下载登记，不会修改已有文件或此前的下载登记。此错误不代表本地图片损坏，无需删除本地文件。对应收藏恢复访问后可重新检查，或在“同步设置 → 同步范围”中选择不包含该漫画的收藏夹后重试；调整范围前需关闭定时同步并保存，避免保存设置时立即触发下载。旧记录缺少阶段信息时不推断失败阶段，仍展示原有错误。

原标题提取代码的第三方许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

| 目录规则 | 【作者】原标题 / 第N話 章节标题；漫画 ID / 章节 ID；漫画标题 [ID] / 章节序号 - 章节标题 [ID]；漫画标题 / 第N話 章节标题；作者 / 漫画标题 [ID] / 章节序号 - 章节标题 [ID] |

默认保存到 `DATA_DIR/jm-favorites`。目录与规则改变不会迁移或清理旧文件；标题/作者变化也可能产生新路径。格式或质量变更时可替换本工具已记录的同路径图片，不覆盖未登记的既有文件。空间不足、权限错误、已存在的未登记文件、上游无效图片会显示失败。

### 服务器目录选择

「同步设置 → 选择服务器目录」浏览的是**服务所在机器的目录**，不是 Windows 浏览器所在设备的磁盘。仅允许管理员通过 `JM_DOWNLOAD_ROOTS` 指定的根目录及其子目录，拒绝路径穿越和子目录符号链接。默认根目录为 `DATA_DIR/jm-favorites`；目录在同步时创建。多个根目录用服务器操作系统的路径分隔符分开（Linux/macOS 为 `:`，Windows 为 `;`）。该环境变量变更需要重启。

Docker 中默认 `/app/data/jm-favorites` 已随数据卷持久化。自定义目录需要**同时配置容器内路径和卷挂载**，例如：

```yaml
services:
  comic-api:
    environment:
      - JM_DOWNLOAD_ROOTS=/app/data/jm-favorites:/downloads
    volumes:
      - ./data:/app/data
      - ./comics:/downloads
```

随后在页面选择 `/downloads` 或其子目录。只有设置环境变量而未挂载卷时，文件仍在容器文件系统，不是宿主机目标目录。备份应包含数据库、密钥以及所有自定义下载根目录；站点鉴权默认关闭，不应开放给不可信用户；开启后通过认证的用户仍具有完整的实例访问权限。

协议依据：[JMComic-Crawler-Python v2.7.8 收藏接口与登录实现](https://github.com/hect0x7/JMComic-Crawler-Python/blob/69afe2c38d09960fd43031826af19095f75a42a2/src/jmcomic/jm_client_impl.py#L963-L1019)。`GET /favorite` 使用 `page/folder_id/o`，解析 `list/folder_list/total`，官方页大小为 20；加入收藏经预检查后使用 `POST /favorite`，表单字段为 `aid`，校验 `status=ok/type=add`。浏览和同步不调用该写入接口。上游接口变化、账号权限或登录失效仍可能导致操作失败。

## 插件扩展

内置插件位于 `src/sources/`；自定义插件放到 `DATA_DIR/plugins/*.py`，重启自动发现。每个模块导出 `create_plugin(store)`，返回 `SourcePlugin` 子类实例，提供唯一 `id`、`name` 与 `capabilities`。插件是**可信的服务器 Python 代码**，没有沙箱；不要安装不可信文件，也不直接兼容 Breeze JavaScript 插件或 Suwayomi APK。

核心接口：

- `search(keyword, page)`：漫画列表，每项含 `id/title/cover/author`；可提供 `authors: [名称]` 和 `page_count: 正整数`，分别表示独立作者及作品总图片页数，用于搜索去重。未知页数省略或设为 `null`，不得填章节数、接口分页总数或 `0`；没有这些可选字段的旧插件继续可用。
- `detail(comic_id)`：漫画详情及 `chapters: [{id, name, order}]`；可附 `tags: [{label, value}]`、`categories: [{label, value}]`，分别表示显示名称与检索值。禁漫/哔咔的标签两者相同，拷贝由 `theme.name/path_word` 映射，缺少有效标识的题材不伪造检索值。
- 可选 `search_tag(keyword, page, tag_value="", sort="")`：声明 `tag_search` 能力后提供图源原生标签检索；可用 `tag_sorts` 声明排序。聚合标签搜索只调用支持此能力的插件，旧插件的 `search(keyword, page)` 签名不变。
- 可选 `search_categories()`：声明 `search_categories` 能力后返回分类选项 `[{label, value}]`，并在 `search` / `search_tag` 中接收可选 `category`。目录应按需获取，不应在构造 manifest 时发出网络请求。
- `pages(comic_id, chapter_id)`：有序图片 URL 列表。
- `client.request(...)`：图片请求客户端应复用 `BaseClient`，其 `request` / `stream` 支持内部 `_image_target` 参数，在隔离连接中固定已校验的目标 IP 与代理；自定义传输不能忽略这一策略。可选 `transform_image(data, chapter_id, url)` 解码图片。
- 可选 `browse(action, **filters)`、`login(values)`、`logout()`、`account_status()`；通过 `categories/sorts/leaderboard_modes/login_fields` 描述界面。
- 可选 `settings_fields`、`settings()` 描述非敏感设置；`save_settings(values)` 持久化并返回替换用的新插件实例。不要把密码或 Token 放进设置清单，应使用登录凭证接口。

参考 `src/sources/bika.py` 的账号插件和 `src/sources/copy.py` 的游客插件。账号可使用 `store.save_account(plugin.id, data)` 保存，加密由存储层处理。

拷贝适配器参考 [Breeze-plugin-copyComic](https://github.com/deretame/Breeze-plugin-copyComic) 的 API 协议，在 Python 中实现搜索、章节分组分页、图片顺序、推荐与排行榜。`COPY_API_BASE` 可修改 API 地址；上游域名、限流与接口变化可能导致服务不可用。

标签检索协议参考：[JM 标签域](https://github.com/hect0x7/JMComic-Crawler-Python/blob/master/src/jmcomic/jm_client_interface.py#L565-L576)、[哔咔标签与分类参数](https://github.com/Miuzarte/PicaComic-go/blob/main/PicaComic.go#L132-L175)、[拷贝题材链接](https://github.com/deretame/Breeze-plugin-copyComic/blob/main/src/index.ts#L1431-L1461)及[完整题材目录](https://github.com/niuhuan/kobi/blob/main/rust/src/copy_client/client.rs#L297-L305)。这些是公开客户端的协议实现，镜像可用性和上游匹配规则仍以上游实际响应为准。

## API

完整参数见 `/docs`。例如 `GET /api/search?keyword=科幻&mode=tag&source=copy&tag_value=kehuan` 按拷贝题材标识查询；`GET /api/search?keyword=职场&source=bika&category=全彩` 组合哔咔关键词与分类，加入 `mode=tag` 则使用标签与分类。

搜索默认不去重，响应的 `items` 保留本页原始结果；只有传入 `deduplicate=true` 才返回去重结果。发生跨 ID 合并的条目附 `variants`（包含主版本在内的原始条目列表，各自保留 `source/id`）；`all_results` 保留各图源的合并前列表，`raw_count` 是原始条目总数，`duplicate_count` 是减少的卡片数。关闭去重时 `duplicate_count` 为 `0`。聚合响应的 `best_match` 始终指向 `items` 首项，空结果为 `null`；这些数量均不是全站命中总数。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET / PUT | `/api/settings/auth` | 读取／保存站点鉴权；密码留空保留，保存需携带 revision，立即生效 |
| GET | `/api/sources` | 插件能力、账号状态与 enabled 开关，不返回凭据；包含已关闭图源 |

## 项目结构

```
main.py                  FastAPI 路由与应用装配
src/auth.py              动态站点 HTTP Basic 鉴权、scrypt 密码校验与设置持久化
src/config.py            JM / Bika 上游端点与密钥
src/storage.py           SQLite 存储（含阅读进度）与 AES-GCM 凭据加密
src/sources/             图源插件抽象与内置插件（bika / jm / copy）
src/clients/             上游协议客户端（签名、解密、HTTP 伪装）
src/services/aggregator.py   插件调度、聚合搜索、标题排序
src/services/image_proxy.py  图片代理：SSRF 防护、并发上限、磁盘缓存
src/services/pdf.py          章节图片并发下载与自适应压缩 PDF
src/services/downloads.py    PDF 下载任务队列与生命周期
src/services/favorite_sync.py  收藏图片同步通用流程：定时调度、本地检查、文件检查点
src/services/jm_sync.py      JM 收藏夹范围与 Pindextitle 章节信息
src/services/bika_sync.py    哔咔收藏扫描与 24 位 ID 规则
src/services/favorites_library_sync.py  JM／哔咔云收藏定时增补书库，不下载图片
src/services/local_images.py 服务器目录边界、带宽限速与图片输出
src/services/images.py       JM 图片反切割
src/web/                 原生 JS 单页界面
tests/                   pytest，无需真实账号
scripts/                 Playwright 界面走查与布局断言（开发用）
```
