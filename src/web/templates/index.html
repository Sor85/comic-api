JM 收藏同步设置

更换或解除账号绑定后，定时同步自动关闭。

更换目录规则保存即同步一次，旧目录未登记时会计为冲突并重复下载。
  1. 1关闭定时同步
  2. 2保存新规则
  3. 3检查本地漫画
  4. 4重新开启同步
详细说明

定时同步开启时，每次保存设置都会立即同步一次，包括仅修改目录规则或下载目录，不会等待下一个周期。

“检查本地漫画”核对目录并登记已有图片，跳过已完成的部分。未登记的原文件不会被覆盖，但会消耗流量和时间。

运行中的任务完成或停止后才能修改设置。

同步计划

下载与图片

限速只作用于同步任务，不影响在线阅读与 PDF。转换格式时动图仅保存首帧，PNG 不使用质量参数。

保存位置

目录在服务器上，不是本机。可选根目录由 JM_DOWNLOAD_ROOTS 决定；Docker 需挂载持久化卷。

目录规则说明
  • 【作者】原标题：对应 JMComic-kit 的 Bd_Aauthoroname_Pindextitle，章节为「第N話 完整标题」，不附加 ID、不合并作者。
  • 超长目录名：超过 255 字节时截短，规则与 JMComic 一致，本地检查按同样规则识别。
  • 无 ID 规则：输出「漫画标题/第1話 章节标题/图片」，不附加 ID；目录已关联其他漫画时报冲突。
  • 已有目录：「检查本地漫画」可识别，无需补 ID；层级只影响新下载，不改名已检查的漫画。

已完成图片会校验并跳过，失败图片下次重试。改目录或层级不会移动旧文件；改格式或质量可能替换同路径图片。同步只写下载目录，不加入书库。

同步范围

收藏夹不勾选任何收藏夹时同步全部收藏；单本与所选同步不受此限制。
