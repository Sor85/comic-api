JM 收藏

漫画详情中的「加入 JM 收藏」写入已绑定账号，不指定收藏夹。收藏浏览、本地同步和本地书库操作不修改远端收藏；本地同步保存解码后的图片，不删除已有文件。

本地同步

本地检查按同步范围核对已有漫画的章节、页数和图片完整性，不下载图片。完整匹配的漫画登记为已下载，后续同步校验后跳过；未匹配、缺页、损坏或重名歧义不会登记。

JM 收藏同步设置

更换或解除账号绑定后，定时同步自动关闭。

目录规则切换说明

定时同步开启时，每次保存设置都会立即同步一次，包括仅修改目录规则或下载目录；不会等待下一个周期，之后按设定间隔运行。

旧漫画尚未通过“检查本地漫画”登记时，可能先重复下载图片，再因目标文件已存在而报告冲突。未登记的原文件不会被覆盖，但会消耗流量和时间。

安全切换顺序：关闭定时同步并保存 → 保存新目录规则 → 完成本地检查并查看结果 → 再开启定时同步。

运行中的任务完成或停止后才能修改设置。

限速只作用于收藏同步图片，不限制在线阅读和现有 PDF 任务。图片先解码再转换；显式转换格式时，动图仅保存首帧。PNG 不使用质量参数。

同步范围

未勾选收藏夹时同步全部收藏。单本及所选同步不受此范围限制。

目录位于运行服务的机器，不是当前浏览器所在设备。可选根目录由 JM_DOWNLOAD_ROOTS 控制，Docker 目录必须挂载持久化卷；可在所选根目录下填写新子目录。

“【作者】原标题 / 第N話 章节标题”对应 JMComic-kit 的 Bd_Aauthoroname_Pindextitle 规则：漫画目录为“【第一作者】原标题”，章节目录为“第N話 完整章节标题”。不附加 ID，不合并多位作者，不去重标题原有的“第N話”。本地检查按相同规则核对目录。

已有“漫画名 / 章节名 / 图片”目录可通过“检查本地漫画”识别，无需补上 ID；下载目录应设为所有漫画文件夹的上一级。目录层级只控制新下载的文件，不会重命名已检查的漫画。

“漫画标题 / 第N話 章节标题”是无 ID 规则，输出为“漫画标题/第1話 章节标题/图片”，不附加 ID，也不使用“001 -”。合法标题不截断；单个目录名超过 255 字节或目录已关联其他漫画时报告冲突。

已完成图片会校验并跳过，失败图片可在下次同步重试。变更目录或层级规则不会移动、清理旧文件；格式或质量变更可能替换本工具已记录的同路径图片。
